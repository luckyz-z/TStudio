# Code of conduct

TStudio is made by producers, for producers, at every skill level. Be the kind of person you'd want in the studio.

- Be kind and patient, especially with beginners. Everybody started with a loop that didn't loop.
- Critique the beat, the code or the idea, never the person.
- No harassment, hate, sexual content aimed at people, or doxxing.
- Don't spam the issue tracker with promotions. Plugin listings go in the TStudio-Plugins repository.
- Credit people. Don't pass off someone else's plugin, preset, sample or code as your own.

Maintainers can edit or remove comments, close issues, and block people who break these rules. Report problems privately to the maintainers through a GitHub security advisory, or contact @Luckyz-z on GitHub.

This code applies to the TStudio repositories, discussions and anywhere else someone represents the project.
